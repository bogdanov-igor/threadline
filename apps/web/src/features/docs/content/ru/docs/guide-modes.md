# Режимы, язык и тема

## «Подробно» и «Кратко»

Режим задаёт, сколько подробностей видно на экране. Данные те же.

Переключатель — в меню профиля: нажмите кружок с инициалами справа в шапке, строка «Режим показа». Выберите нужный вариант: страница сразу сменит вид, меню остаётся открытым. Поиск при этом не прерывается.

**«Подробно»** показывает всё:

![Список запросов в режиме «Подробно»: адреса, компонент, число записей, ID запроса](shot:guide-modes-full)

**«Кратко»** убирает техническое:

![Тот же список в режиме «Кратко»: только статус, время, запрос, итог и длительность](shot:guide-modes-brief)

## Что убирает «Кратко»

| Где | Чего нет в «Кратко» |
|---|---|
| Список запросов | Компонента, числа записей, ID запроса, HTTP-метода, вкладки «Все записи» |
| Шапка запроса | HTTP-метода, ID запроса, ссылки «Открыть в Grafana» |
| Схема | Адресов и кодов. Те же шаги на тех же местах, вместо кодов слова |
| Панель шага | Адреса, HTTP-статуса, кодов, уровня записи, вида «Как в логе», кнопок справочника и cURL |
| Операция | Полного id и ID запросов |

Если подробности скрыты, внизу панели шага написано «Часть подробностей — в режиме «Подробно»» и есть кнопка «Подробно».

Набор колонок и вкладок для каждого режима может настроить аналитик: «Настройки проекта», пункт «Вид». Там же задан режим по умолчанию.

## Что видно всегда

Никакой режим не скрывает:

- порядок шагов, имена шагов и систем;
- статусы запроса и операции;
- итог и причину ошибки;
- пометки о неполных данных, например «записи неполные» и «неточное совпадение».

## «Кратко» не защищает данные

«Кратко» только убирает подробности с экрана. Скрытое остаётся в браузере. Кто угодно может вернуть «Подробно».

Данные защищают маски и роли.

У роли Бизнес другое дело. У неё всегда «Кратко» и нет переключателя. Подробностей нет даже в браузере: сервер их не отдаёт.

Одно исключение: на странице короткой ссылки переключатель есть у всех. Подробности там под маской.

## Где хранится выбор

Выбор запоминается в этом браузере, один на все проекты. Пока вы его не сделали, действует режим, заданный в настройке проекта. В ссылку выбор не входит: коллега откроет страницу в своём режиме.

## Язык

1. Нажмите кружок с инициалами.
2. В строке «Язык» выберите «Русский» или «English».

![Меню профиля: режим показа, язык и тема](shot:guide-modes-language)

Страница не перезагружается. Введённое остаётся на месте, идущий поиск продолжается.

Логи и справочник не переводятся: они показаны так, как записаны.

Выбор запоминается в этом браузере. В другом браузере интерфейс снова будет на русском.

## Тема

В том же меню в строке «Тема» выберите «Светлая», «Тёмная» или «Как в системе». Выбор тоже запоминается в этом браузере.
