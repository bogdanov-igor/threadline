# Все поля

Полная таблица формата. Читайте её как справочник: что значат поля и как их писать, подробно описано на остальных страницах.

Как читать:

- Каждая таблица относится к одному виду записи. Над таблицей написано, где эта запись лежит в файле. `systems[]` значит каждый элемент списка `systems`.
- Точка значит вложенное поле: `status.in` это поле `in` внутри `status`.
- Фигурные скобки значат каждое из перечисленного: `columns.{time,request}.full` это `columns.time.full` и `columns.request.full`.
- «Обязательно» считается внутри своей записи. Если необязательного `status` нет, поле `status.path` не нужно.
- Строка-значение у необязательного текстового поля может быть и `null`: это то же, что нет поля.

Таблица сверяется со схемой `config/catalog/catalog.schema.json` при каждом прогоне тестов: новое поле без описания их не пройдёт.
## Верх файла

Запись: сам файл.

| Поле | Тип | Обязательно | По умолчанию | Что делает |
|---|---|---|---|---|
| `$schema` | строка | нет |  | Ссылка на схему для редактора кода. На проект не влияет |
| `version` | только `1` | да |  | Версия формата. Поддерживается только `1` |
| `project` | строка | да |  | Идентификатор проекта. Должен совпасть с проектом, в который загружают файл |
| `settings` | объект | нет | нет раздела: настройки не меняются | Настройки проекта |
| `idTypes` | список | нет | нет раздела: ничего не меняется | Типы id |
| `systems` | список | нет | нет раздела: ничего не меняется | Система проекта и внешние системы |
| `general` | объект | нет | нет раздела: ничего не меняется | Общие правила проекта |
| `masking` | список | нет | нет раздела: настройка не меняется | Виды масок |

## Настройки

Запись: `settings`.

| Поле | Тип | Обязательно | По умолчанию | Что делает |
|---|---|---|---|---|
| `name` | строка | да |  | Название проекта, до 80 символов. Видно в шапке |
| `timezone` | строка | да |  | Часовой пояс проекта: `Europe/Berlin`. По нему показано всё время |
| `retentionDays` | число | да |  | Срок хранения логов в днях: целое от 1 до 400. Период поиска не может быть старше |
| `format` | строка | да |  | Имя формата логов: встроенный `json` или формат из файла настроек |
| `environments` | список | да |  | Среды проекта, порядок хранится. Среды, которых здесь нет, остаются |
| `view` | объект | нет | нет поля: настройка не меняется | Вид страниц |

### Среды

Запись: `settings.environments[]`.

| Поле | Тип | Обязательно | По умолчанию | Что делает |
|---|---|---|---|---|
| `id` | строка | да |  | Идентификатор среды: строчная латиница, цифры, дефис, до 32 символов. Новый `id` это новая среда |
| `name` | строка | да |  | Название среды, до 80 символов |
| `kind` | одно из: `single`, `pr-stands` | нет | `single` | `single`: обычная среда. `pr-stands`: стенды pull request |
| `backend` | строка | да |  | Имя хранилища из файла настроек |
| `selector` | список | нет | пустой список | Условия: какие записи читает среда. У обычной среды нужно хотя бы одно `=`, всего до 20 |
| `selector[].label` | строка | да |  | Имя метки хранилища: латиница, цифры и `_` |
| `selector[].op` | одно из: `=`, `!=`, `=~`, `!~` | да |  | Сравнение. В YAML всегда в кавычках |
| `selector[].value` | строка | да |  | Значение метки, до 256 символов |
| `selector[].searchOnly` | `true` или `false` | нет | нет | `true`: исключение только для обычного поиска. Бывает только у `!=` |
| `stand` | объект | нет |  | Метка и шаблон стенда. Только у `pr-stands`, там обязателен |
| `stand.label` | строка | да |  | Имя метки хранилища |
| `stand.template` | строка | да |  | Шаблон значения метки с одним местом `{number}` |
| `examples` | список | нет | нет поля: примеров нет | Примеры поиска на странице среды, до 6 |
| `examples[].label` | строка или объект | да |  | Подпись карточки, до 60 символов: строка на все языки или своя на каждом языке интерфейса |
| `examples[].label.{ru,en}` | строка | нет |  | Подпись на этом языке. Нет её — видна подпись на другом языке |
| `examples[].values` | список | да |  | Значения поиска: от 1 до 5, по правилам строки поиска |
| `examples[].period` | одно из: `15m`, `1h`, `6h`, `24h` | нет | `6h` | Период поиска |

Примеры поиска (`examples`) — карточки на странице среды до первого поиска: щелчок заполняет строку поиска значениями примера и сразу ищет за его период. Подпись пишется строкой или по языкам: `label: { ru: 'Отказ проверки личности', en: 'Identity check failed' }`. Значения проверяются так же, как в строке поиска: без запятых, кавычек и обратной косой черты, хотя бы одно не короче 6 символов. Маскирование файла значения примеров не проверяет: номер карты на карточке закрыт маской, но в файле и в браузере он целиком. Пишите только выдуманные или тестовые значения.

### Вид страниц

Запись: `settings.view`.

Если поле есть, пишите его целиком: проще всего взять из выгрузки. `full` значит показывать в режиме «Подробно», `brief` в режиме «Кратко».

| Поле | Тип | Обязательно | По умолчанию | Что делает |
|---|---|---|---|---|
| `defaultMode` | одно из: `full`, `brief` | да |  | Режим у тех, кто ещё не выбирал его сам. Встроенное значение `full` |
| `columns` | объект | да |  | Колонки списка запросов |
| `columns.{time,request,outcome}` | объект | да |  | Колонки «Время», «Запрос», «Итог». Не выключаются |
| `columns.{time,request,outcome}.{full,brief}` | только `true` | да |  | Всегда `true` |
| `columns.{component,duration,records,cid}` | объект | да |  | Колонки «Компонент», «Длительность», «Записей», «ID запроса» |
| `columns.{component,duration,records,cid}.{full,brief}` | `true` или `false` | да |  | Показывать ли в этом режиме |
| `defaultTab` | одно из: `scheme`, `timeline`, `records` | да |  | Вкладка при открытии запроса. Не может быть выключенной в обоих режимах. Встроенное значение `scheme` |
| `tabs` | объект | да |  | Вкладки запроса. «Шкала времени» есть всегда, её здесь нет |
| `tabs.{scheme,records}` | объект | да |  | Вкладки «Схема» и «Записи» |
| `tabs.{scheme,records}.{full,brief}` | `true` или `false` | да |  | Показывать ли в этом режиме |
| `blocks` | объект | да |  | Блоки панели шага |
| `blocks.{request,response,headers,context,raw,logs}` | объект | да |  | Блоки «Запрос», «Ответ», «Заголовки», «Контекст», «Сырые записи», «Логи» |
| `blocks.{request,response,headers,context,logs}.{full,brief}` | `true` или `false` | да |  | Показывать ли в этом режиме |
| `blocks.raw.full` | только `true` | да |  | Всегда `true`: нераспознанная запись видна только там |
| `blocks.raw.brief` | `true` или `false` | да |  | Показывать ли в режиме «Кратко» |
| `bodyView` | одно из: `pretty`, `raw` | да |  | Вид тел: «Отформатированный» или «Как в логе». Встроенное значение `pretty` |

## Типы id

Запись: `idTypes[]`.

| Поле | Тип | Обязательно | По умолчанию | Что делает |
|---|---|---|---|---|
| `key` | строка | да |  | Ключ типа: латиница в нижнем регистре, цифры и `_`, с буквы, до 32 символов |
| `kind` | одно из: `entity`, `operation` | да |  | `entity`: сущность, на страницах запроса и операции не показана. `operation`: операция, от неё появляется кнопка «Открыть операцию» |
| `name` | строка | да |  | Название типа, до 80 символов |
| `statuses` | список | нет | нет словаря | Словарь статусов по порядку жизни операции, до 30. Только у `operation` |
| `statuses[].value` | строка | да |  | Значение как в логе, до 64 символов. Цифры в кавычках |
| `statuses[].name` | строка | да |  | Название статуса, до 80 символов |
| `statuses[].outcome` | одно из: `pending`, `success`, `failure` | да |  | `pending`: ещё идёт. `success`: успех. `failure`: отказ |
| `hidden` | `true` или `false` | нет | `false` | `true`: тип скрыт. Тип, на который ссылаются методы, скрыть нельзя |

## Системы

Запись: `systems[]`.

| Поле | Тип | Обязательно | По умолчанию | Что делает |
|---|---|---|---|---|
| `key` | строка | да |  | Постоянный ключ: строчная латиница, цифры, дефис, до 32 символов. У системы проекта равен идентификатору проекта |
| `kind` | одно из: `project`, `external` | нет | `external` | `project`: система самого проекта, одна. `external`: внешняя система |
| `type` | одно из: `service`, `database`, `queue` | нет | `service` | `service`: HTTP, SOAP, JSON-RPC. `database`: база. `queue`: шина, отдельных шагов в логах нет. У базы и шины нет методов |
| `name` | строка | да |  | Название, до 80 символов. Видно на схеме, в списке и в причинах |
| `hosts` | список | нет | пустой список | Шаблоны хостов, до 50: `host`, `host:port`, `[ipv6]:port`, `*.domain`. Один шаблон у одной системы |
| `description` | строка | нет | пусто | Как отвечает система, до 500 символов. Видно только в справочнике |
| `hidden` | `true` или `false` | нет | `false` | `true`: система и всё внутри неё не действуют. Систему проекта скрыть нельзя |
| `methods` | список | нет | нет записей | Методы |
| `errors` | список | нет | нет записей | Правила ошибок |
| `outcomes` | список | нет | нет записей | Правила итога. У базы и шины не работают |

## Методы

Запись: `systems[].methods[]`.

| Поле | Тип | Обязательно | По умолчанию | Что делает |
|---|---|---|---|---|
| `http` | одно из: `GET`, `POST`, `PUT`, `PATCH`, `DELETE`, `HEAD`, `OPTIONS`, `*` | да |  | HTTP-метод заглавными или `'*'`, это любой |
| `path` | строка | да |  | Шаблон пути: начинается с `/`, подстановка `{имя}` занимает часть целиком, без строки запроса, до 512 символов |
| `rpc` | строка | нет | пусто | Действие SOAP или JSON-RPC, до 128 символов. Только для вызовов, у входа не читается: проверка предупредит |
| `name` | строка | да |  | Название, до 80 символов. Видно на схеме, в списке и в причинах |
| `domain` | строка | нет | пусто | Группа метода, до 40 символов. Видно только в справочнике |
| `description` | строка | нет | пусто | Что делает метод, до 500 символов. Видно только в форме метода |
| `kind` | одно из: `call`, `start`, `status`, `callback` | нет | `call` | `call`: обычный. `start`: создаёт операцию. `status`: отдаёт статус. `callback`: колбэк в проект, только у системы проекта |
| `op` | строка | нет | пусто | Ключ типа вида `operation`. Обязателен у `start`, `status`, `callback` |
| `fields` | список | нет | пустой список | Id не в пути, до 10 |
| `fields[].in` | одно из: `query`, `request`, `response` | да |  | `query`: строка запроса. `request`: тело запроса. `response`: тело ответа |
| `fields[].path` | строка | да |  | Путь поля, до 128 символов. JSON: имена через точку, без массивов. XML: имя элемента. У `query`: имя параметра |
| `fields[].type` | строка | да |  | Ключ типа id из `idTypes` |
| `status` | объект | нет | пусто | Где лежит статус операции. Только у метода с `op` |
| `status.in` | одно из: `request`, `response` | да |  | `request` или `response` |
| `status.path` | строка | да |  | Путь поля, правила те же |
| `status.map` | объект | нет | нет перевода | Перевод значений из лога в значения словаря, без учёта регистра. Значения: строки до 64 символов из словаря типа |
| `hidden` | `true` или `false` | нет | `false` | `true`: метод не действует |

## Правила ошибок

Записи: `systems[].errors[]` и `general.errors[]`.

Поля с `method` бывают только в `systems`.

| Поле | Тип | Обязательно | По умолчанию | Что делает |
|---|---|---|---|---|
| `method` | объект | нет | нет: правило всей системы | Ссылка на метод этой системы. Делает правило правилом метода |
| `method.http` | одно из: `GET`, `POST`, `PUT`, `PATCH`, `DELETE`, `HEAD`, `OPTIONS`, `*` | да |  | HTTP-метод, как у метода |
| `method.path` | строка | да |  | Шаблон пути, как у метода. Имена подстановок могут отличаться |
| `method.rpc` | строка | нет | пусто | Действие, как у метода |
| `http` | целое | нет | нет условия | Условие: настоящий HTTP-статус ответа, от 100 до 599. У базы не работает |
| `code` | строка или целое | нет | нет условия | Условие: код ошибки, до 64 символов. Коды из цифр сравниваются как числа |
| `text` | строка | нет | нет условия | Условие: подстрока текста ошибки, от 3 до 200 символов, без учёта регистра, лишних пробелов и переводов строк |
| `title` | строка | да |  | Понятный текст ошибки, до 200 символов |
| `action` | строка | нет | пусто | «Что делать», до 500 символов |
| `severity` | одно из: `error`, `ok` | нет | `error` | `error`: ошибка. `ok`: шаг не красный, «по справочнику не ошибка» |
| `partnerCode` | строка | нет | пусто | Код, который партнёр получит от проекта, до 64 символов |
| `hidden` | `true` или `false` | нет | `false` | `true`: правило не действует |

## Правила итога

Записи: `systems[].outcomes[]` и `general.outcomes[]`.

Поля с `method` бывают только в `systems`.

| Поле | Тип | Обязательно | По умолчанию | Что делает |
|---|---|---|---|---|
| `method` | объект | нет | нет: правило всей системы | Ссылка на метод этой системы. Делает правило правилом метода |
| `method.http` | одно из: `GET`, `POST`, `PUT`, `PATCH`, `DELETE`, `HEAD`, `OPTIONS`, `*` | да |  | HTTP-метод, как у метода |
| `method.path` | строка | да |  | Шаблон пути, как у метода |
| `method.rpc` | строка | нет | пусто | Действие, как у метода |
| `priority` | целое | нет | `100` | Порядок внутри уровня, от 1 до 1000. Меньше раньше |
| `when` | объект | да |  | Условия. Нужно хотя бы одно, подходит, если выполнены все |
| `when.http` | целое или объект или список | нет | нет условия | HTTP-статус: число, диапазон `{ from, to }` или список до 20 элементов |
| `when.http.from` | целое | да |  | Начало диапазона, включительно |
| `when.http.to` | целое | да |  | Конец диапазона, включительно |
| `when.fields` | список | нет | нет условий | Условия на поля тела, до 10 |
| `when.fields[].in` | одно из: `response`, `request` | нет | `response` | `response`: тело ответа. `request`: тело отправки этого вызова |
| `when.fields[].path` | строка | да |  | Путь поля, до 128 символов. JSON: имена через точку, без массивов. XML: имя элемента |
| `when.fields[].equals` | строка или число или `true` или `false` | нет | нет проверки | Равно. Без пробелов по краям и без учёта регистра, до 200 символов |
| `when.fields[].oneOf` | список | нет | нет проверки | Одно из значений, до 50 |
| `when.fields[].exists` | `true` или `false` | нет | нет проверки | `true`: поле есть и не `null`. `false`: поля нет или оно `null` |
| `when.fields[].regex` | строка | нет | нет проверки | Выражение по значению поля, до 200 символов. Регистр учитывается. Флаги только в начале: `(?i)`, `(?s)` или `(?is)` |
| `outcome` | одно из: `success`, `error`, `pending`, `ignore` | да |  | `success`: успех. `error`: ошибка. `pending`: в обработке. `ignore`: не ошибка |
| `text` | строка | нет | пусто | Свой текст или шаблон с `{путь}`, до 5 мест, до 200 символов |
| `action` | строка | нет | пусто | «Что делать», до 500 символов |
| `hidden` | `true` или `false` | нет | `false` | `true`: правило не действует |

У условия на поле ровно одна проверка: `equals`, `oneOf`, `exists` или `regex`.

## Общие правила

Запись: `general`.

| Поле | Тип | Обязательно | По умолчанию | Что делает |
|---|---|---|---|---|
| `errors` | список | нет | нет записей | Правила ошибок на весь проект. Проверяются после правил метода и системы. Одного `http` здесь мало: проверка предупредит |
| `outcomes` | список | нет | нет записей | Правила итога на весь проект. Проверяются после правил метода и системы |

## Маскирование

Запись: `masking[]`.

| Поле | Тип | Обязательно | По умолчанию | Что делает |
|---|---|---|---|---|
| `type` | одно из: `card_number`, `secrets`, `card_data`, `card_token`, `account_number`, `phone`, `national_id`, `passport`, `surname`, `first_name`, `birth_date`, `email`, `address` | да |  | Вид маски |
| `enabled` | `true` или `false` | да |  | Включён ли вид. У `card_number` и `secrets` только `true` |
| `keys` | список | нет | пустой список | Поля, добавленные к встроенным, до 200. Имя от 1 до 64 символов: латиница, цифры, `_`, `.`, `:` и `-` |
