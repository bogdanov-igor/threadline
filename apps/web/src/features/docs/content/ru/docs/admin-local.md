# Локальный режим

Эта страница для того, кто запускает Threadline у себя на компьютере, без Kubernetes и без PostgreSQL. Пользователь один, вход выключен, адрес только `127.0.0.1`. Свою Grafana или свой Loki вы подключаете прямо в интерфейсе.

## Что нужно заранее

- Node.js 24 и pnpm.
- Копия репозитория Threadline.
- Адрес своей Grafana и токен сервисного аккаунта с ролью Viewer. Или адрес Loki, если ходите в него напрямую.

## Шаг 1. Запустите

В корне репозитория:

```bash
pnpm install
pnpm local
```

Первый запуск собирает интерфейс, это около минуты. Потом Threadline сам открывает браузер на `http://127.0.0.1:8080/`. Если порт 8080 занят, берётся следующий свободный. Адрес печатается в терминале.

Остановить — Ctrl+C в терминале. Повторный `pnpm local` с той же папкой данных не запускает вторую копию, а открывает уже работающую.

После обновления репозитория через `git pull` соберите интерфейс заново: `pnpm install && pnpm build`, затем `pnpm local`. Сама команда собирает интерфейс, только когда его ещё нет.

| Параметр | Что делает |
|---|---|
| `--port 8085` | свой порт; если он занят, Threadline не запустится и скажет об этом |
| `--data ~/threadline-work` | своя папка данных, то же делает переменная `THREADLINE_DATA` |
| `--no-open` | не открывать браузер |

Параметры пишутся после двух дефисов: `pnpm local -- --port 8085 --no-open`.

## Шаг 2. Посмотрите демо

На первом запуске открывается демо-проект Demo Pay. Его записи выдуманы, в сеть Threadline за ними не ходит. Сверху стартовой страницы стоит призыв «Подключить хранилище», под ним примеры поиска: щелчок по примеру сразу ищет. Призыв можно скрыть крестиком, в этом браузере он больше не появится.

## Шаг 3. Подключите хранилище

Нажмите «Подключить хранилище». Та же страница открывается из меню профиля, пункт «Хранилища», и кнопкой «Подключить хранилище» в разделе «Состояние» на странице «Настройки сервиса»; адрес `/admin/storages`.

1. Выберите, что подключаете: Grafana или Loki напрямую.
2. Для Grafana укажите адрес, например `https://grafana.example`, токен сервисного аккаунта и источник Loki: по имени, uid или id.
3. Для Loki укажите адрес, например `http://localhost:3100`, и вход: без входа, токен Bearer или имя и пароль. Арендатор нужен, только если Loki с несколькими арендаторами.
4. «Метка сред» — метка, по которой различаются ваши сервисы, обычно `namespace`, `service_name` или `job`. Каждая среда проекта на этом хранилище будет условием равенства на неё.
5. Нажмите «Проверить». Threadline сходит в хранилище тем же запросом, что кнопка «Проверить» в строке хранилища на странице «Настройки сервиса».
6. Нажмите «Сохранить». Хранилище работает сразу, перезапуск не нужен.

## Шаг 4. Создайте проект

После сохранения нажмите «Создать проект». Задайте название и среду, в поле хранилища выберите только что подключённое, в условиях среды — равенство на метку сред, например `namespace = shop`. Дальше поиск работает как на сервере.

## Где что лежит

Всё хранится в папке данных, по умолчанию `~/.threadline`. Папка создаётся с правами только для вас.

| Файл | Что в нём |
|---|---|
| `threadline.yaml` | настройка: создана на первом запуске, демо-проект и вход выключен |
| `storages.json` | подключённые хранилища: адреса и **токены**, права `0600` |
| `db/` | встроенная база PGlite: проекты, справочник, настройки |
| `catalog/`, `logos/` | начальный набор справочника и логотипы демо-проекта |

Токен и пароль хранятся только в `storages.json`. В браузер они не передаются, страница показывает лишь «токен задан». В журнал они тоже не пишутся.

Сменить токен: удалите хранилище на странице и подключите заново с тем же именем. Среды на нём снова заработают.

Свой корневой сертификат для Grafana или Loki задаётся переменной Node: `NODE_EXTRA_CA_CERTS=/путь/к/root-ca.pem pnpm local`. Прокси берётся из `HTTPS_PROXY` и `NO_PROXY`.

## Как начать заново

Остановите Threadline и удалите папку данных:

```bash
rm -rf ~/.threadline
```

Следующий `pnpm local` создаст её снова, с демо-проектом и без хранилищ.

## Чего в этом режиме нет

- Входа и ролей: каждый, кто открыл адрес, — администратор. Поэтому адрес только `127.0.0.1`, другой Threadline в этом режиме не примет.
- Файла `.env` и переменных `THREADLINE_*` сервера: настройка целиком в папке данных.
- Работы в сети на несколько человек. Для неё нужен сервер со входом, страница «Установка».
