# Операция

Операция: одно дело клиента, которое в логах разбито на несколько запросов.

Возьмём перевод. Клиент видит одно действие, а в логах их четыре:

![Четыре запроса одного перевода: создание, отправка, колбэк, опросы. Общий у них только id перевода](diagram:guide-operation)

1. **Создание.** Партнёр просит сделать перевод. Это один запрос.
2. **Отправка.** Фоновая задача отправляет перевод в другую систему. Это другой запрос со своим ID.
3. **Колбэк.** Та система сама сообщает результат. Колбэк: вызов, которым внешняя система сообщает о себе первой. Это третий запрос.
4. **Опросы.** Партнёр несколько раз спрашивает статус. Это ещё запросы.

Каждый из них может быть зелёным, а перевод при этом не прошёл. Страница одного запроса этого не покажет. Страница операции собирает всё, что связано id перевода, и показывает, чем кончилось дело.

## Когда она нужна

- Клиент говорит «деньги не дошли», а найденный запрос зелёный.
- Нужно узнать, чем кончился платёж или перевод, а не один вызов.
- Нужно понять, кто что вызывал и в каком порядке.

Если ошибка в одном запросе и её причина понятна, операция не нужна.

## Как открыть

1. Найдите любой запрос этого перевода. Удобнее всего поиском по id перевода.
2. Откройте запрос.
3. В шапке нажмите «Открыть операцию». На кнопке тип операции и последние 4 символа id.

![Шапка запроса с кнопкой «Открыть операцию · Transfer …5c6d»](shot:guide-operation-button)

Если кнопка ведёт себя иначе:

- **Кнопки нет.** В этом запросе нет id операции, или такой id не описан в справочнике.
- **Кнопка неактивна, подсказка «id скрыт маскированием».** Threadline не ищет операцию по маске.
- **Кнопка спрашивает «Какую операцию открыть».** В запросе их несколько. Выберите нужную.

## Как читать страницу

![Страница операции, цифрами отмечены итог, фраза о случившемся, ход операции, список запросов и окно поиска](shot:guide-operation-page)

1. **Итог.** Чем кончилось дело.
2. **Что случилось.** Одна-две фразы: чем кончилась операция, в каком запросе причина и что делать. Ссылка в тексте открывает этот запрос. Threadline берёт самый ранний запрос с ошибкой: поздние часто только повторяют её.
3. **«Ход операции».** Статусы по времени и запрос, откуда взят каждый статус.
4. **«Запросы операции».** Все запросы одной таблицей: кто позвал, когда, сколько шло, чем кончилось. Полоска в строке показывает место запроса на общей шкале, поэтому паузы видны как расстояние.
5. **Окно поиска.** В каком времени искать.

### Что значит итог

| На экране | Что значит |
|---|---|
| «Completed», «Declined» и другие слова из справочника | Последний итоговый статус операции. |
| «В процессе» | Итогового статуса пока нет. Нажмите «Обновить» позже. |
| «Итог не прочитан» | В логах нет статусов. Рядом написано, сколько запросов с ошибкой. |
| «по колбэку» | Статус есть только в колбэке. Что сервис сделал с этим колбэком, логи не подтверждают. |
| «по неполным данным» | Часть запросов или записей не прочитана. |

### Строка запроса

Нажмите стрелку справа в строке. Под ней появятся шаги этого запроса маленькой схемой и кнопка «Открыть запрос».

![Раскрытая строка: шаги запроса на маленькой схеме и кнопка «Открыть запрос»](shot:guide-operation-row)

На странице запроса вверху будет «К операции» и «Запрос 1 из 3». Так можно ходить между запросами одной операции.

Строка «Опросы партнёра ×6» собирает одинаковые вопросы партнёра о статусе. Threadline их не читает: ответ партнёру в лог не пишется. Поэтому время опросов известно только приблизительно. Если опросы идут дольше запросов, их полоска доходит до края шкалы и растворяется.

## Окно поиска

Threadline ищет запросы операции около момента открытого запроса: «±3 ч» или «±12 ч». Запрос вне окна на страницу не попадёт.

| На экране | Что делать |
|---|---|
| «Других запросов в окне не найдено.» | Нажмите «Искать в окне ±12 ч». |
| «Искать и по id «…»» | Нашёлся ещё один id этой операции, например выданный другой системой. Нажмите, чтобы найти запросы и по нему. |
| «N запросов в 13:00–19:00 не прочитаны» | Threadline читает не больше 200 запросов и 20 000 строк. Сузьте окно, чтобы прочитать эти. |
| «Операции дольше 24 часов собираются только в окне ±12 часов.» | Целиком такую операцию страница не покажет. |
| «Поиск остановлен» | Поиск прервала ошибка. Найденное осталось. Нажмите «Повторить». |

Уход на другую страницу останавливает поиск. При возврате он запускается заново. Переход к запросу этой операции поиск не останавливает.

## Что скрыто

Личные данные на этой странице всегда под маской. Кнопки «Показать скрытое» здесь нет. Откройте сам запрос, чтобы увидеть больше.

У роли Бизнес и в режиме «Кратко» нет полного id и ID запросов.
