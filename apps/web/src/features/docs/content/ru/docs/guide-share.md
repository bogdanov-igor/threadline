# Поделиться

Кнопка «Поделиться» стоит в результатах поиска, на странице запроса и на странице операции. Она есть у всех ролей.

## Что в меню

![Меню «Поделиться»: короткая ссылка, текст для тикета, ID запроса, справа то, что будет скопировано](shot:guide-share-menu)

| Пункт | Что копирует |
|---|---|
| «Короткая ссылка» | Адрес, который откроется у коллеги без входа. |
| «Текст для тикета» | Готовый текст: название, время, среда, причина, ID запроса и короткая ссылка. |
| «ID запроса» | Только ID. Этот пункт есть на странице запроса, кроме роли Бизнес. У неё и в тексте для тикета ID нет. |

Справа в меню видно, что будет скопировано. После нажатия кнопка пишет, что всё скопировано.

## Что получит коллега

Ссылка открывается без входа и без роли. Все видят одно и то же.

![Страница по короткой ссылке: метка «Открыто по ссылке», срок действия, запрос под маской](shot:guide-share-open)

- В шапке метка «Открыто по ссылке · только чтение» и кнопка «Войти в Threadline».
- Вверху написано, до какой даты ссылка действует.
- Поиск выполняется заново по условиям, которые вы задали: те же значения, те же среды, тот же период точными датами. Через неделю ссылка читает то же время.
- Переключатель «Подробно» и «Кратко» есть у всех, в том числе у Бизнеса. В «Подробно» видны адреса и тела под маской.

## Что скрыто

- Номера карт, личные данные и секреты всегда под маской. Кнопки «Показать скрытое» нет ни у кого, даже у администратора.
- Значения поиска тоже скрыты: телефон и номер карты маской, обычный текст звёздочками. Только длинный id вида UUID виден как есть. Подсветки найденного нет.
- От номера карты в ссылке хранятся только первые 6 и последние 4 цифры. Поэтому результаты могут получить пометку «неточное совпадение».
- Нельзя менять поиск, период и среду. Нет «Обновить», «Открыть в Grafana», cURL и правки справочника.

> Имя, отчество, дата рождения и e-mail маска по умолчанию не скрывает. Помните об этом, когда пересылаете ссылку.

## Сколько живёт ссылка

По умолчанию 30 дней. Точная дата видна при создании ссылки и на её странице. Срок задаёт администратор на странице «Настройки сервиса».

- Если срок сократить, он сразу действует и на старые ссылки.
- Если срок продлить, он действует только на новые.

Списка ссылок нет. Отозвать одну ссылку нельзя. Если ссылка ушла не туда, попросите администратора сократить срок: перестанут открываться все ссылки старше нового срока.

## Текст для тикета

1. Нажмите «Поделиться».
2. Выберите «Текст для тикета». Текст скопируется.
3. Вставьте его в тикет.

Текст выглядит так:

```text
**Оплата услуги · Ошибка**
06.11.2026 08:26:08 (UTC+00:00) · Prod
Причина: Недостаточно средств
Где: Платёжный шлюз, Списание
ID запроса: 0000000000000
https://threadline.corp.example/s/…
```

Значения в тексте всегда под маской, даже если вы открыли скрытое на странице. Если ссылку создать не удалось, текст скопируется без неё и кнопка об этом скажет.

## Короткая ссылка или адрес из браузера

| | Короткая ссылка | Адрес страницы запроса |
|---|---|---|
| Нужен вход | Нет | Да |
| Что видно | Одно и то же у всех | Зависит от роли того, кто открыл |
| Маска | Открыть нельзя | Открывается по правилам роли |
| Срок | 30 дней по умолчанию | Пока живут логи |

Адрес страницы результатов поиска работает только у вас. У коллеги он покажет, что результат устарел. Для результатов всегда берите короткую ссылку.

## Если не вышло

| На экране | Что значит и что делать |
|---|---|
| Кнопка недоступна | Подсказка называет причину. Чаще всего база ссылок недоступна. Пока можно передать адрес страницы запроса тем, кто входит в Threadline. |
| «Поиск устарел, повторите его и поделитесь снова.» | Результат поиска уже удалён. Нажмите «Обновить» и поделитесь снова. |
| «Ссылка больше не действует» | Срок истёк или такой ссылки нет. Попросите новую. |
| «Записи этого периода уже удалены» | Логи старше срока хранения. Открыть их нельзя. |
| «Проект сейчас недоступен», «Такой среды больше нет», «Среда сейчас не настроена» | Спросите того, кто прислал ссылку. Если проект и среду вернут, ссылка снова заработает. |
| «Сервис занят, повторите» | Сейчас идёт много поисков по ссылкам. Повторите через несколько секунд. |
| «Ссылки сейчас недоступны, повторите» | База ссылок не отвечает. Сама ссылка не пропала. |
