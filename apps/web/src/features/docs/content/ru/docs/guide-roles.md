# Роли и маски

Роль определяет, что вы видите и что можете менять. Ролей пять. Роль одна на весь Threadline, во всех проектах одинаковая.

## Как узнать свою роль

Нажмите кружок с инициалами в правом верхнем углу. В меню ваше имя и роль.

![Меню пользователя: имя, роль «Поддержка», язык, тема, «Выйти»](shot:guide-roles-menu)

Кнопок, которые вашей роли не положены, на экране просто нет. Это не поломка.

Сменить роль в Threadline нельзя. Её выдаёт администратор службы входа, например Keycloak. Новая роль заработает сама, заново входить не нужно. Если ролей несколько, действует самая сильная.

## Три слова для таблиц

- **Технические подробности:** адреса, коды ответов, заголовки, тела запросов и ответов, строки лога как есть.
- **Личные данные:** телефон, личный номер, паспорт, фамилия, адрес, номер счёта, срок действия карты.
- **Секреты:** пароли, PIN, CVV, токены, ключи доступа.

## Бизнес

Для тех, кому нужно понять, что случилось, без технических подробностей.

| Что | Как у этой роли |
|---|---|
| Поиск | Есть, те же значения |
| Список запросов, операция | Есть, в кратком виде |
| Страница запроса | Свой простой экран: статус, название, начало и длительность, шаги по порядку. Шаг без названия в справочнике подписан именем системы, запрос без названия читается «Запрос без названия». Схемы, шкалы времени и панели шага нет |
| Причина ошибки | Словами справочника и «Что делать». Если ошибка не описана, какой шаг не прошёл, общие слова и просьба передать ссылку в поддержку |
| Технические подробности | Нет |
| Личные данные, номера карт, секреты | Нет, и открыть нельзя |
| «Поделиться» | Есть. Пункта «ID запроса» нет, и в тексте для тикета ID нет |
| Справочник, настройки проекта, страница «Настройки сервиса» | Нет |

![Страница запроса у роли Бизнес: шаги по порядку, какой шаг не прошёл, просьба передать ссылку в поддержку](shot:guide-roles-business)

## Поддержка

Для второй линии и клиентской поддержки.

| Что | Как у этой роли |
|---|---|
| Поиск, запросы, операции | Есть, всё |
| Технические подробности | Есть |
| Личные данные и номер карты | Под маской. Открываются кнопкой на одном запросе |
| Секреты | Под маской. Открыть нельзя |
| Справочник | Читает весь. Добавляет и правит только ошибки |
| «Неизвестное» | Скрывает и возвращает только строки об ошибках |
| Файл проекта | Читает и скачивает |
| Настройки проекта | Только читает. Может проверить подключение |
| Страница «Настройки сервиса» | Есть |

## Разработчик

Всё, что у поддержки, и ещё:

| Что | Как у этой роли |
|---|---|
| Справочник | Правит всё: системы, методы, ошибки, правила итога, типы id |
| «Неизвестное» | Работает со всеми строками |
| Файл проекта | Меняет раздел справочника |
| Настройки проекта, маскирование | Только читает |

## Аналитик

Всё, что у разработчика, и ещё:

| Что | Как у этой роли |
|---|---|
| Личные данные | Видит сразу, без кнопки, в подробностях запроса |
| Номер карты, секреты | Под маской. Открываются кнопкой на одном запросе |
| Настройки проекта | Правит название, среды и вид страниц. Скрывает и показывает проекты |
| Новый проект, удаление навсегда, маскирование | Нет |

## Администратор

Всё, что у аналитика, и ещё:

| Что | Как у этой роли |
|---|---|
| Проекты | Создаёт и удаляет навсегда |
| Маскирование | Включает и выключает виды данных |
| Настройки на странице «Настройки сервиса» | Срок жизни коротких ссылок, контакт поддержки |

Токены и пароли самого сервиса не видны никому, даже администратору.

> Значок человека с оранжевой точкой вместо инициалов значит, что этот Threadline работает без входа: в меню профиля написано «Вход выключен». У всех права администратора, но кнопка не открывает номера карт и секреты.

## Маски

Маска: звёздочки вместо значения. Её ставит сервер ещё до отправки в браузер. Поэтому скрытого значения нет даже в браузере.

| Что скрыто | Как выглядит | Кто открывает кнопкой | Кому открыто сразу |
|---|---|---|---|
| Номер карты | `411111******7893` | Поддержка, Разработчик, Аналитик, Администратор | Никому |
| Секреты | `***` | Аналитик, Администратор | Никому |
| Телефон | `+********0001` | Поддержка, Разработчик | Аналитик, Администратор |
| Личный номер | `*****101A` | Поддержка, Разработчик | Аналитик, Администратор |
| Паспорт | `AA*****01` | Поддержка, Разработчик | Аналитик, Администратор |
| Номер счёта | `****…6001` | Поддержка, Разработчик | Аналитик, Администратор |
| Фамилия, полное имя | `Т***** Т*****` | Поддержка, Разработчик | Аналитик, Администратор |
| Адрес, данные и токен карты | `***` | Поддержка, Разработчик | Аналитик, Администратор |

Бизнес не открывает ничего. На короткой ссылке не открывает никто.

Имя, отчество, дата рождения и e-mail по умолчанию не скрыты. Их может включить администратор.

Администратор может и выключить вид данных для проекта. Номер карты и секреты не выключаются никогда.

## Кнопка «Показать скрытое»

В обиходе её зовут глазком: на ней нарисован глаз. Она стоит в шапке запроса.

1. Откройте запрос.
2. Нажмите «Показать скрытое». Кнопка сменится на «Скрыть».
3. Значения откроются в панели шага на всех шагах и на вкладке «Записи».

Было:

![Панель шага: в теле запроса номер карты под маской](shot:guide-roles-mask)

Стало:

![Та же панель: номер карты открыт, кнопка называется «Скрыть»](shot:guide-roles-open)

Подсказка на кнопке называет, что останется под маской.

![Подсказка кнопки «Показать скрытое»: останутся под маской секреты](shot:guide-roles-hint)

Открытое снова скрывается, когда вы нажали «Скрыть», перешли к другому запросу или ушли со страницы. В ссылку показ не входит.

**Что остаётся под маской всегда:** список запросов, красная полоса с причиной, шаги на схеме, заголовки шагов, форма справочника, текст для тикета, страница операции, вкладка «Все записи».

**Когда кнопки нет:**

- на странице нечего открывать;
- у вас роль Бизнес;
- это страница короткой ссылки;
- режим «Кратко» на этом проекте не показывает подробности.

**Когда кнопка не помогает.** Если приложение скрыло значение ещё до записи в лог, Threadline его не вернёт. Он показывает то, что лежит в логе.

Threadline не записывает, кто и что открывал.

## Пример: номер карты в Postman

Вам нужно повторить вызов в Postman с настоящим номером карты.

1. Откройте запрос и нажмите шаг, где есть этот номер.
2. Нажмите «Показать скрытое».
3. Нажмите «Скопировать как cURL». Номер скопируется открытым.
4. В Postman нажмите Import и вставьте текст.
5. Вместо `***` подставьте свой ключ: секреты в команду не попадают.
6. В Threadline нажмите «Скрыть».

> Номер карты вставляйте только туда, где он нужен для работы. В тикет и чат кладите короткую ссылку: там всё под маской.
