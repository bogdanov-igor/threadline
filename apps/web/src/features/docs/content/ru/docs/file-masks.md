# Маскирование

Маска: звёздочки вместо части значения или всего значения. Раздел `masking` говорит, какие виды данных скрывать и какие поля к ним добавить.

Менять раздел может только Администратор. Файл, который меняет раздел от другой роли, не применяется целиком: `раздел маскирования меняет только администратор: файл не применён`. Раздел, совпавший с базой, правкой не считается, поэтому остальные роли могут оставить его в тексте как есть.

## Пример

```yaml full
version: 1
project: acme
masking:
  - type: phone
    enabled: true
    keys:
      - client_mobile_alt
      - contact_person_phone
  - type: address
    enabled: false
  - type: email
    enabled: true
```

Этот файл делает три вещи: добавляет телефону два поля, выключает адрес и включает e-mail. Остальные виды не меняются.

## Поля

| Поле | Обязательно | Что писать |
|---|---|---|
| `type` | да | Код вида, таблица ниже |
| `enabled` | да | `true` или `false` |
| `keys` | нет | Поля, добавленные к встроенным. Нет поля: список пуст |

Каждая строка задаёт вид целиком. Стёрли `keys`: добавленных полей у вида больше нет.

Вида нет в разделе: он не меняется. Раздела нет: настройка не меняется.

## Виды

| `type` | Название на экране | Включён сразу | Можно выключить | Маска |
|---|---|---|---|---|
| `card_number` | Номер карты | да | нет | `000000******0000` |
| `secrets` | Секреты | да | нет | `***` |
| `card_data` | Данные карты | да | да | `***` |
| `card_token` | Токен карты | да | да | `***` |
| `account_number` | Номер счёта | да | да | `****…6001` |
| `phone` | Телефон | да | да | `+********0001` |
| `national_id` | Личный номер | да | да | `*****101A` |
| `passport` | Паспорт | да | да | `AA*****01` |
| `surname` | Фамилия | да | да | `Т*****` |
| `first_name` | Имя и отчество | нет | да | `Т*****` |
| `birth_date` | Дата рождения | нет | да | `***` |
| `email` | E-mail | нет | да | `u*****@example.com` |
| `address` | Адрес | да | да | `***` |

У `card_number` и `secrets` нет выключателя. `enabled: false` у них даёт ошибку, а `enabled: true` с полями `keys` принимается.

В выгрузке раздел всегда перечисляет все виды.

## Что значит выключить вид

Значения этого вида открываются всем пользователям проекта во всех его средах: и в проде, и в тесте. Настройка одна на проект, по средам не различается.

Открыты они только в блоках подробностей записи. Заголовки, причины ошибки, итог шага, подсказки и схема остаются под маской.

В других проектах вид остаётся включённым. Номера карт и секреты эта настройка не затрагивает.

Отчёт предупреждает о выключении отдельно. В командной строке это строка `Внимание: вид «Адрес» выключается, значения откроются всем пользователям проекта во всех средах`.

## Добавленные поля

Встроенные поля в файл не пишутся и не убираются. Сюда идут только поля вашей системы, которых нет во встроенном списке: например, `client_mobile_alt`.

Имя поля: от 1 до 64 символов, латиница, цифры, `_`, `.`, `:` и `-`. Регистр, `_` и `-` при сравнении не важны: `client_mobile` и `clientMobile` это одно поле. У вида до 200 добавленных полей.

Что нельзя:

- Поле другого вида. `password` принадлежит виду «Секреты», `card_number` виду «Номер карты», `first_name` виду «Имя и отчество». Ошибка: `поле уже есть у вида «Секреты»`.
- Одно поле дважды.

## Как маски влияют на остальной файл

Проверка отклоняет текст, который маска изменила бы. Значение в сообщение не попадает, только путь к нему.

- **Значения в текстах.** Номер карты или телефон в `name`, `title`, `description` и других полях: `уберите номер карты, секрет или значение другого вида маски: маскирование скрыло бы часть текста`.
- **Имена полей.** Встроенные поля видов, включённых по умолчанию, и секреты нельзя указывать как id, поле статуса, `{путь}`, `equals`, `oneOf` и `regex`. Можно только `exists`: оно значение не открывает.
- **Поля, которые вы добавили к виду.** Их указывать можно: значение будет показано маской.
- **Настройка проекта.** Текст проверяется и встроенными масками, и настройкой этого проекта. Разделы `masking` и `settings.view` не проверяются: в них имена полей и постоянные значения.

Скрыть вид нельзя, только выключить. Поле `hidden` в строке вида даёт ошибку.

## Ручные правки

Вид, который правили на форме «Маскирование», файл без «Заменить ручные правки» не меняет. Он попадёт в группу «Ручные правки пропущены».

## Начальный набор

Файл `config/catalog/<проект>.yaml` сервер загружает сам при подключении к базе. Маски он не меняет: раздел `masking` в нём пропускается, остальное применяется, а в журнале будет предупреждение.

Поэтому такой файл не выключит маску в другой среде. Новая база получает встроенные маски: включено всё, кроме имени и отчества, даты рождения и e-mail.

Меняет маски Администратор: на этой странице файла или на форме «Маскирование».
