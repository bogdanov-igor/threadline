# Найти причину ошибки по ID запроса

**Для кого:** Поддержка, Разработчик, Аналитик.

**Задача:** в тикете есть ID запроса. Нужно понять, что случилось.

1. Вставьте ID запроса в поле поиска и нажмите Enter. Выберите «24 ч» и нажмите «Найти».

   ![Строка поиска: в поле метка с ID запроса, выбрано «24 ч», цифрами отмечены поле, период и «Найти»](shot:learn-find-paste)

2. В списке будет один запрос. Нажмите его строку.

   ![Один найденный запрос со статусом «Ошибка» и причиной в колонке «Итог»](shot:learn-find-results)

3. Откроется страница запроса. Красный шаг на схеме показывает, где сломалось. Threadline уже выбрал его.

   ![Страница запроса: схема с красным шагом, панель справа](shot:learn-find-request)

4. Прочитайте красную полосу: что случилось, в какой системе и на каком шаге. Нажмите её: раскроются «Что делать» и то, чья это ошибка.

   ![Красная полоса: «Not enough money in the customer's account», система, шаг, справа кнопка «что делать»](shot:learn-find-reason)

5. Если нужно увидеть доказательство, в панели справа нажмите строку «Ответ» в «Данных шага». Тело ответа откроется в большом окне. Красная строка показывает, откуда взята причина.

   ![Большое окно: тело ответа, строка с причиной выделена красным](shot:learn-find-body)

## Что должно получиться

Вы знаете три вещи: что случилось, в какой системе и что делать дальше.

Если запрос не нашёлся, задайте период через «Свой» и проверьте среду. Если красной полосы нет, ошибок в запросе нет.
