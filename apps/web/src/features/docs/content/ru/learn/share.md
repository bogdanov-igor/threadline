# Передать случай коллеге

**Для кого:** все роли.

**Задача:** вы нашли запрос. Коллега должен увидеть то же самое без лишних объяснений.

1. На странице запроса нажмите «Поделиться». Откроется меню. Справа видно, что будет скопировано.

   ![Меню «Поделиться»: «Короткая ссылка», «Текст для тикета», «ID запроса» и образец текста](shot:learn-share-menu)

2. Выберите «Текст для тикета». Кнопка покажет, что всё скопировано. Вставьте текст в тикет: там название, время, среда, причина, ID запроса и короткая ссылка.

   ![Шапка запроса: на кнопке написано, что текст скопирован](shot:learn-share-done)

   Нужна только ссылка, например для чата? Выберите «Короткая ссылка».

3. Коллега открывает ссылку. Входить ему не нужно. Он видит тот же запрос под маской, только для чтения.

   ![Страница по ссылке: метка «Открыто по ссылке», срок действия, тот же запрос](shot:learn-share-open)

## Что должно получиться

В тикете лежит текст со ссылкой. Коллега открывает её и сразу видит запрос.

Запомните три вещи:

- Ссылка живёт 30 дней, если администратор не задал другой срок.
- Значения в тексте и по ссылке под маской, даже если вы открыли скрытое.
- Имя, отчество, дата рождения и e-mail маска по умолчанию не скрывает. Думайте, кому отправляете.
