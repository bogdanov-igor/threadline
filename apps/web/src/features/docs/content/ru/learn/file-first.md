# Первый файл проекта, короткая версия

**Для кого:** Разработчик, Аналитик, Администратор.

**Задача:** описать одну систему и одну её ошибку через файл. Проект уже создан.

1. Нажмите название проекта в шапке, затем «Справочник», затем «Файл проекта». Откроется весь проект одним текстом.

   ![Страница «Файл проекта»: текст с номерами строк, «Скачать», «Загрузить файл»](shot:learn-file-open)

2. Выделите весь текст и вставьте этот. Поставьте свой проект и хост. Записи, которых нет в тексте, останутся в проекте.

   ```yaml
   version: 1
   project: pay
   systems:
     - key: fraud
       name: Проверка мошенничества
       hosts:
         - fraud.pay.example:9090
       errors:
         - http: 500
           title: Проверка не смогла обработать запрос
           action: Повторите позже. Если повторяется, напишите в поддержку сервиса проверки.
   ```

3. Подождите пару секунд. Threadline проверит текст и напишет, что будет добавлено. Ошибка в тексте будет отмечена у своей строки. Нажмите «Применить 2 изменения».

   ![Отчёт проверки: будет добавлено две записи, кнопка «Применить 2 изменения»](shot:learn-file-typed)

4. Threadline подтвердит запись и покажет свежий текст проекта.

   ![Сообщение «Файл загружен: изменено 2 записи»](shot:learn-file-applied)

5. Откройте запрос с этой системой. Там теперь её имя и ваш текст ошибки.

   ![Страница запроса: система «Проверка мошенничества», текст ошибки и «Что делать»](shot:learn-file-result)

## Что должно получиться

Вместо адреса видно имя системы, вместо HTTP 500 ваше предложение. Заново читать логи не нужно.

Если кнопки «Применить» нет, в тексте ошибка или менять нечего. Если вы Поддержка, файл открыт только для чтения.

Подробно: [Файл проекта](/docs/file-start).
