# Взять номер карты в Postman

**Для кого:** Поддержка, Разработчик, Аналитик, Администратор.

**Задача:** повторить вызов в Postman с настоящим номером карты.

1. Найдите запрос и откройте его. Нажмите шаг, где есть номер. В «Данных шага» строка «Запрос» показывает строку тела с номером. Номер стоит под маской.

   ![Страница запроса: выбран шаг, в теле запроса номер под маской](shot:learn-postman-step)

2. В шапке нажмите «Показать скрытое». Номер откроется. Кнопка сменится на «Скрыть».

   ![Та же страница: номер открыт, кнопка называется «Скрыть»](shot:learn-postman-open)

3. Нажмите «Скопировать как cURL». Команда с открытым номером попадёт в буфер. На кнопке на секунду появятся галочка и слово «Скопировано».

   ![Панель шага, цифрой отмечена кнопка «Скопировать как cURL»](shot:learn-postman-curl)

4. В Postman нажмите Import и вставьте текст. Секреты в команде остаются `***`: подставьте свой ключ доступа. Нажмите Send.

   ![Четыре шага: скопировать в Threadline, Import в Postman, подставить свой ключ, Send](diagram:learn-postman)

5. Вернитесь в Threadline и нажмите «Скрыть». Значения снова под маской.

   ![Шапка запроса, цифрой отмечена кнопка «Скрыть»](shot:learn-postman-hide)

## Что должно получиться

Вызов повторён в Postman, а в Threadline снова всё скрыто.

Если нужен только номер, выделите его в теле и скопируйте обычным способом.

Если номер остался со звёздочками, приложение скрыло его ещё до записи в лог. Вернуть его нельзя.

Не вставляйте номер в тикет и чат. Для этого есть короткая ссылка: там всё под маской.
