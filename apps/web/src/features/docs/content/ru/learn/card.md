# Найти запросы по карте

**Для кого:** Поддержка, Разработчик, Аналитик.

**Задача:** клиент назвал номер карты. Нужно найти все его запросы за день.

1. Вставьте номер карты в поле поиска и нажмите Enter. Номер сразу станет маской. Метка покажет «номер карты». Выберите «24 ч».

   ![Строка поиска: метка «номер карты» с маской, выбрано «24 ч»](shot:learn-card-field)

2. Нажмите «Найти» и прочитайте список. Статус и колонка «Итог» показывают, чем кончился каждый запрос.

   ![Список запросов по карте: успешные и с ошибкой, у одного пометка «неточное совпадение»](shot:learn-card-results)

   Пометка «неточное совпадение» значит, что полного номера в этих записях нет, только его края. Такие края могут быть и у другой карты.

3. Нажмите строку нужного запроса. Вверху справа написано, в скольких записях найдена карта.

   ![Страница запроса: «Значение найдено в 6 записях из 13» и кнопка «К первому»](shot:learn-card-hit)

4. Нажмите «К первому». Откроется вкладка «Записи», первая запись с картой раскрыта. Найденный номер подсвечен.

   ![Вкладка «Записи»: раскрытая запись, номер карты подсвечен жёлтым](shot:learn-card-records)

## Что должно получиться

Вы видите все запросы этой карты за выбранный период и знаете, где в запросе встречается её номер.

На экране номер под маской. После перезагрузки страницы его нужно ввести заново. Если запросов слишком много, сузьте период.
