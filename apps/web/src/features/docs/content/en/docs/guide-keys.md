# Keyboard shortcuts

Keys speed up your work but open nothing new: everything is also on the buttons. The list window opens with the `?` key or the “Keyboard shortcuts” item in the “Help” menu.

## Keys

| Key | What it does | Where it works |
| --- | --- | --- |
| `?` | Shows the window with the list of keys | Everywhere |
| `/` | Puts the cursor in the search field | On the search page and in the catalog |
| `J` | Next request step | On the request page, “Diagram” and “Timeline” tabs |
| `K` | Previous request step | On the request page, “Diagram” and “Timeline” tabs |
| `]` | Next search result | On a request page opened from the results list |
| `[` | Previous search result | On a request page opened from the results list |
| `L` | Copies the short link | Where there is a “Share” button |
| `T` | Copies the text for a ticket | Where there is a “Share” button |
| `Esc` | Closes a window or menu, the large code window too. In the search field it just leaves the field | Everywhere |

Holding `J` or `K` moves through the steps in a row. On the first and last step the selection stays in place.

## When keys do not work

- The cursor is in an input field. Letters then just type text. Press `Esc` to leave the search field.
- A window or menu is open. The large code window has its own keys: `J` and `K` move through steps, `/` puts the cursor into the text search.
- Ctrl, ⌘ or Alt is pressed. The browser page search `Ctrl+F` works as usual.
- There is no such button here. If a short link is unavailable, `L` does nothing. The “Records” tab has no steps, so `J` and `K` do nothing. If a request is opened by a direct link or the page was reloaded, there is no list, so `[` and `]` do nothing.

The keyboard layout does not matter: the keys work the same on the Russian layout as on the English one, because the service looks at the key itself, not the letter.

On a short link page, `?`, `J`, `K`, `[`, `]`, `L` and `Esc` work. The `L` key copies the address of this same page.

## In forms

- `Tab` goes to the next field, `Shift+Tab` to the previous one. From the last field `Tab` goes to the main button, then to “Cancel”.
- `Enter` in a single-line field applies or saves the form.
- `Ctrl+Enter` or `⌘+Enter` saves a form with multi-line text. In the project file the “Apply” button works the same way.
- `Esc` closes the window, and focus returns to where it was opened from.
- If a form was not saved, the cursor goes to the first invalid field, and the message is next to it.

In a group of buttons, for example the period choice, `Tab` stops once. Inside the group, arrows move between buttons, and Space or `Enter` selects.

## Search values field

- `Enter` or a comma adds a value. `Enter` in an empty field starts the search.
- `Ctrl+Enter` starts the search at once, even if the value has not been added yet.
- `Backspace` in an empty field removes the last value.
- The left arrow from an empty field goes to the values, and `Delete` removes the selected one.

## Date and time fields

Inside a field, you type digits in a row and the cursor moves to the next part itself. Left and right arrows move between parts, up and down change the value. `Tab` goes straight to the next field. The calendar opens with the icon in the field.

The year is accepted from 2000 to 2099. If the start is later than the end, the message is under the fields and the cursor returns to “Start”.
