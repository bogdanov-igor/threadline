# Find requests by card

**For:** Support, Developer, Analyst.

**Task:** a client gave a card number. You need to find all their requests for the day.

1. Paste the card number into the search field and press Enter. The number becomes a mask at once. The label shows “card number”. Choose “24 h”.

   ![Search bar: the “card number” label with a mask, “24 h” selected](shot:learn-card-field)

2. Click “Find” and read the list. The status and the “Outcome” column show how each request ended.

   ![Requests found by card: successful ones and ones with an error, one marked “inexact match”](shot:learn-card-results)

   The “inexact match” mark means that the full number is not in these records, only its first and last digits. Another card may have the same first and last digits.

3. Click the row of the request you need. The top right says how many records the card was found in.

   ![Request page: “Value found in 6 records of 13” and the “To first match” button](shot:learn-card-hit)

4. Click “To first match”. The “Records” tab opens with the first record with the card expanded. The found number is highlighted.

   ![“Records” tab: an expanded record, with the card number highlighted in yellow](shot:learn-card-records)

## What you should get

You see all requests for this card in the chosen period, and you know where in the request its number appears.

The number is masked on the screen. After a page reload you need to enter it again. If there are too many requests, narrow the period.
