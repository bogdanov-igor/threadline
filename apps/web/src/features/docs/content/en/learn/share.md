# Pass a case to a colleague

**For:** all roles.

**Task:** you found a request. A colleague must see the same thing without extra explanations.

1. On the request page click “Share”. A menu opens. On the right you can see what will be copied.

   ![“Share” menu: “Short link”, “Text for a ticket”, “Request ID” and a text sample](shot:learn-share-menu)

2. Choose “Text for a ticket”. The button shows that everything was copied. Paste the text into the ticket: it has the name, time, environment, reason, request ID and short link.

   ![Request header: the button says that the text was copied](shot:learn-share-done)

   Do you need only the link, for example for a chat? Choose “Short link”.

3. The colleague opens the link. They do not need to sign in. They see the same request, masked, read only.

   ![Page opened by link: the “Opened by link” label, the expiry date, the same request](shot:learn-share-open)

## What you should get

The ticket has the text with the link. The colleague opens it and sees the request at once.

Remember three things:

- A link lives 30 days, unless an administrator set another lifetime.
- Values in the text and on the link are masked, even if you revealed hidden values.
- The mask does not hide first name, patronymic, date of birth and e-mail by default. Think about who you are sending it to.
